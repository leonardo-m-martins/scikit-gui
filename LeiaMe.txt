Requerimentos:
- Python 3.13 ou superior com tkinter

Como rodar:
- Instalar os pacotes de requirements.txt
    pip install -r requirements.txt
- Rodar main.py
    python main.py

Interface:
- O slider "Padrão" / "CONFIG.json" corresponde ao seletor "Padrão" e
  inicia no modo "CONFIG.json", arraste para alterá-lo.
    - "Padrão": executa o método com os parâmetros padrão do scikit.
    - "CONFIG.json": executa o método com os parâmetros do arquivo.
- O botão "Executar Todos" executa todos os métodos do modo selecionado para o
  dataset selecionado.
OBS: não é recomendado utilizar o botão "Executar Todos" no slider "Padrão",
já que alguns métodos podem levar vários minutos em OnlineNewsPopularity.arff.

Abas:
- "Resumo Dados": resumo do dataset carregado.
- "Dados": tabela com as amostras do dataset, com paginação.
- "Resultados": lista das execuções e detalhes das métricas do resultado
  selecionado.

Configurações:
- Cada método possui um arquivo CONFIG.json próprio:
    config/classificacao/<metodo>/CONFIG.json
    config/regressao/<metodo>/CONFIG.json
  O CONFIG.json é o arquivo de configuração do método.
- O slider "Padrão" / "CONFIG.json" escolhe a origem dos parâmetros.
  O valor inicial é "CONFIG.json".
- O botão "Parâmetros" abre o editor do método selecionado:
    - "Aplicar": aplica as alterações apenas à sessão atual, sem gravar.
    - "Exportar": grava as alterações no CONFIG.json do método.
    - "Importar": carrega um arquivo JSON para o editor.

Formato do CONFIG.json:
{
  "version": 1,
  "mode": "Classificação",
  "method": "Decision Tree",
  "preprocessing": "Nenhum",
  "params": {
    "criterion": "entropy",
    "random_state": 42
  }
}

Campos:
- mode: "Classificação" ou "Regressão".
- method: nome do método, igual ao exibido na interface.
- preprocessing: "Nenhum", "StandardScaler", "MinMaxScaler" ou
  "RobustScaler".
- params: hiperparâmetros do modelo.

Datasets:
- data/spambase.arff: dataset de classificação.
- data/OnlineNewsPopularity.arff: dataset de regressão.
